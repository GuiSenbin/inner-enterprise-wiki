## 1. 总体设计
[[产品生命周期管理系统]]采用“前端工作台 + 后端接口 + 数据存储 + 日志审计”的轻量架构。技术选型包括[[PostgreSQL]]、[[Vue]]、[[FastAPI]]、[[Nginx]]、[[Docker]]，优先满足可维护、易部署和便于[[监控运维]]的要求。

## 2. 技术组件
| 组件 | 用途 | 责任部门 |
| --- | --- | --- |
| [[PostgreSQL]] | 业务数据、配置数据和审计记录存储。 | [[信息技术部]] |
| [[Vue]] | 内部管理后台和业务工作台前端。 | [[信息技术部]] |
| [[FastAPI]] | 内部接口服务和轻量后端能力。 | [[信息技术部]] |
| [[Nginx]] | 反向代理、静态资源和内网访问入口。 | [[信息技术部]] |
| [[Docker]] | 开发、测试和演示环境一致化部署。 | [[信息技术部]] |

## 3. 数据流
1. 业务人员在[[Vue]]工作台提交或查询数据。
2. 后端服务由[[FastAPI]]承载，完成[[身份认证]]、[[权限管理]]和业务规则校验。
3. 业务数据写入[[PostgreSQL]]，批处理结果按项目规则归档。
4. 关键事件进入[[审计日志]]，运行状态纳入[[监控运维]]巡检。

## 4. 安全与接口
系统接口遵循[[接口设计]]规范，所有内部调用需要携带用户身份信息。涉及敏感字段时执行[[数据脱敏]]，涉及审批事项时进入[[审批流]]。
